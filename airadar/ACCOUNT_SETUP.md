## 가입 → 자동화까지 순서

1. [ ] x.com에서 계정 생성 (위 핸들/bio 붙여넣기)
2. [ ] 고정 트윗 올리기
3. [ ] developer.x.com → Free 플랜 → 앱 생성 → User auth 키 4개 발급
4. [ ] `~/devin/airadar/.env`에 X_API_KEY 등 입력
5. [ ] `config.yaml`에서 `post_to_x: true` — 처음엔 `dry_run: true` 유지하고 `python -m airadar post`로 미리보기 확인
6. [ ] 마음에 들면 `dry_run: false`로 전환
7. [ ] Gmail 앱 비밀번호 → `.env`에 SMTP 입력 → 이메일 다이제스트 켜기
8. [ ] launchd 등록으로 4시간마다 자동 실행 (간격 변경은 plist의 `StartInterval` 수정)
