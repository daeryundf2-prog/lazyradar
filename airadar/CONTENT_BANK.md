# 콘텐츠 소재 뱅크 — 본인 작업물 기반 "직접 쓸 글감"

자동 포스팅 말고 사람이 직접 쓰는 글 소재. 한 번 쓴 건 [x] 체크.

## 딥페이크 포렌식 (전문성 소재)

- [ ] "딥페이크 탐지 앙상블 돌렸더니 AUROC 0.43 나옴" — 동전던지기보다 못한 결과 공개 (스레드 소재)
- [ ] C2PA 매니페스트 뜯어보기 — 서명 검증되면 뭐가 나오는지 스크린샷 시리즈
- [ ] "C2PA 없다고 가짜 아님" — 증거 없음 ≠ 가짜 증거, 짧은 스레드
- [ ] H.264/DAV 포렌식 — CCTV 영상에서 진위 검증하는 법 (frametrace 작업 연계)
- [ ] E01 이미지 무결성 검증 과정 — 해시 체인이 뭔지 쉽게 풀기
- [ ] "탐지 확률 87%"가 나오는 이유 — 벤치마크 없는 확률 표기 비판

## 도구/개발 뒷얘기 (제작자 서사)

- [ ] 왜 딥페이크 포렌식 도구를 만들었나
- [ ] 오픈소스로 포렌식 도구 만들 때의 고민 (오남용 vs 투명성)
- [ ] 법률 문서 자동 생성기 만든 얘기 (omni-store)
- [ ] AI 에이전트로 포렌식 검증 자동화한 과정
- [ ] 실패한 벤치마크 공개하기의 가치
